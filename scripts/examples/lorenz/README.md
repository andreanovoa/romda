# Lorenz twin experiments

## What the example shows

Twin experiments on two chaotic systems: the truth is generated by the model itself, noisy observations
are sampled from it, and an ensemble with perturbed initial states and parameters is filtered in real
time.

- **`lorenz63`** (Lorenz 1963). Two of the three state variables are measured, and the parameters `rho`
  and `beta` are estimated together with the state. The filter is the square-root EnKF by default; with
  a manual bias on the observations, the regularized bias-aware EnKF (rBA-EnKF) estimates the bias with
  an echo state network.
- **`lorenz96`** (Lorenz 1996, 40 sites on a ring). Every second site is measured, and the forcing `F` is
  estimated together with the state.

The two sweeps show how the filter responds to the ensemble size, the time between observations, the
covariance inflation, the observation noise and, for the bias-aware filter, the regularization of the
bias.

## Data

None: the truth is generated on the fly.

## How to run

From the repository root:

```bash
python scripts/examples/lorenz/lorenz63.py --save-figs          # Lorenz 63, figures to figs/
python scripts/run_config.py examples/lorenz/lorenz96  # Lorenz 96
python -m romda.run scripts/examples/lorenz/lorenz63.yml --set truth.manual_bias=linear_offset --set da.method=rBA_EnKF
```

The sweeps take `--study <name>`, and `--quick` runs two values of each setting as a smoke test:

```bash
python scripts/examples/lorenz/sweeps_lorenz63.py --study ensemble_size --quick
python scripts/examples/lorenz/sweeps_lorenz96.py --study observation_sparsity
```

| Script | Study | Setting varied | What to look for |
|---|---|---|---|
| `sweeps_lorenz63.py` | `ensemble_size` | members `m`, EnKF and EnSRKF | the error saturates with `m`; the square-root filter tolerates a smaller ensemble, because it does not perturb the observations |
| | `assimilation_frequency` | time steps between observations `Nt_obs` | the filter loses the chaotic truth once the time between analyses approaches the error-doubling time |
| | `inflation` | multiplicative inflation factor | the error is U-shaped: the spread collapses without inflation, and the filter fits the noise with too much |
| | `observation_noise` | true noise level and assumed `std_obs` | an assumed observation error below the true noise over-trusts the data and can destabilize the filter; note the two scales: `noise_level` is a standard deviation, `std_obs` a variance, both relative to the signal amplitude |
| | `regularization` | rBA-EnKF regularization factor, biased observations | zero keeps the bias correction but drops its penalty; a plateau of near-optimal values means the method is easy to tune |
| `sweeps_lorenz96.py` | `ensemble_size` | members `m`, EnKF and EnSRKF | `m` below the 40 sites is the rank-deficient regime, in which inflation becomes critical |
| | `observation_sparsity` | `Nt_obs` and the spacing of the measured sites, in one figure | how far the filter can be pushed with sparse sensors in time and in space, and whether the two interact |
| | `inflation` | multiplicative inflation factor, small `m` | the inflation needed to prevent the divergence of an undersampled ensemble |

To check the consistency of a filter, compare the spread with the error: in a well-tuned filter they are
of the same size.

## Outputs

In this folder, not tracked by git:

- `figs/`: the figures of the cases (`lorenz63_01.png`, `lorenz96_01.png`, ...) and of the sweeps
  (`lorenz63_<study>.png`, `lorenz96_<study>.png`);
- `results/`: the records of the sweeps (`lorenz63_<study>.jsonl`, `lorenz96_<study>.jsonl`), one line per run.

The bias-aware runs also cache the training data of the echo state network under `results/lorenz63/`, and
the trained network under `results/esn_configs/`, both at the repository root.
