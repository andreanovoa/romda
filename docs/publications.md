# Publications

The works below are produced with `romda`. Each entry links the paper, the release of the code that produced it,
and the folder of [`scripts/`](https://github.com/andreanovoa/romda/tree/main/scripts) that holds its
experiments.

## Replications

Two works are replicated with the current code. Each page sets the figures beside the conclusions of the paper.

- [Nóvoa, Racca & Magri (2023), CMAME](publications/replication_cmame2023.md): the regularized bias-aware EnKF on
  the Van der Pol oscillator and the Rijke tube.
- [Nóvoa & Magri (2025), ICCS](publications/replication_iccs2025.md): online learning of a POD-ESN of the cylinder
  wake.
